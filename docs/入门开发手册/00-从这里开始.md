# Spark 的日记：从看热闹到看懂代码

> 2026-11-25 内容更新：网站项目清单已换成 Spark 的首个真实项目“爱心点阵”，旧教学项目与示例日志已移除。本手册主体保留 2026-11-24 的代码快照，用于学习当时的结构；当前项目文件在 `projects/heart-matrix/`。

Spark，这份手册是给第一次做网站的人写的。你不需要先记住一堆英文词，也不用从最复杂的星球开始学。先弄明白：**一个网站，就是一批文件，加上让它们配合工作的程序。**

现在先暂停加功能，把已经做出来的东西看懂。以后这个网站的重点，是装下你的学习资料、动手项目和自己的理解。

## 先验收，再决定是否导入 Obsidian

这些都是普通 Markdown 文件。当前仅放在项目的 `docs/入门开发手册/`，没有复制到你的 Obsidian 库，也没有覆盖旧开发笔记。

- [ ] 我能说清楚 HTML、CSS、JavaScript 分别做什么。
- [ ] 我知道更改网页、保存 Git 提交、推送 GitHub、线上部署是四件事。
- [ ] 我知道自己的文章与收藏分别放在哪里。
- [ ] 我能找到不懂的地方，并指出希望讲得更慢的章节。
- [ ] 内容和讲法合适后，再决定整套导入，还是只保留其中几篇。

以后导入时，可以整体复制这个文件夹，保留内部文件名和子目录，这样章节间的相对链接仍能配合使用。它不会因此自动与网站同步。[Obsidian 的 Markdown 说明](https://obsidian.md/help/syntax)
