# 每次只学一个小本领

建议每次约 30–45 分钟：先看十分钟，动手二十分钟，再用五分钟写一句“我明白了什么”。下面十次练习按能力顺序安排，不要求十天内完成。

第一遍目标是**能维护自己的文字、收藏和文章**。星球的数学、数据库权限与服务器部署，可以稍后深入。

## 开始前：把本机小店开起来

用 VS Code 打开 `E:\chatGPTproject\neon-lab` 文件夹，再打开终端。也可以直接使用 PowerShell：

```powershell
cd E:\chatGPTproject\neon-lab
node --version
$env:HOST='127.0.0.1'
node server.mjs
```

项目要求 Node.js 22 或更高版本。`node --version` 查看当前安装版本，不会修改项目。若提示找不到命令，先看 [Node.js 官方入口](https://nodejs.org/)，安装后重新打开终端。

运行最后一行后，终端可能一直停在 `Local: http://127.0.0.1:…`。这是正常的：它正在等浏览器来访问，不是卡死。打开终端显示的地址；端口以输出为准，默认是 4177。停止服务可在这个终端按 `Ctrl+C`。

`127.0.0.1` 表示自己的电脑，端口像楼里的窗口编号。同一个端口被占用时，不要随便关闭别人的程序，可以换用另一个空闲端口，并以新输出地址访问。

修改 HTML / CSS 后通常刷新页面即可；修改服务端 JavaScript 或 `.env` 后，要停止并重新启动服务。本机已有配置时，不要用空白样本覆盖 `.env`。

第一次练习不要追求“改得漂亮”，而是每次都知道**改了哪里、为什么起作用、怎么验证**。复杂错误也尽量缩小到一个文件、一项操作。

## 把一小段 JavaScript 读成中文

下面是资料读取的教学简化版，不是需要另行添加到项目的功能：

```javascript
const response = await fetch('./data/resources.json');
if (!response.ok) throw new Error('资料没有取到');
const data = await response.json();
const items = data.embedded;
```

逐行翻译：

1. `fetch`：去指定地址取资料；`await`：等这件事返回结果再继续这段流程，不是把整个浏览器冻住。
2. 看有没有成功，失败就交给错误处理。
3. 把返回的 JSON 文字读成程序可使用的对象。
4. 从对象里拿出 `embedded` 这一组资料。

`const` 是给一个值起名字，并规定这个名字不能被重新指向另一个值；它并不意味着对象内部绝对不能改变。初学先理解“我给这个结果起了个名字”。

真正的 `resources.js` 还会遍历每一项、创建标题和链接，失败时显示提示。不要把“代码能跑完”只理解成没有红字：最终页面也要符合预期。

## 学会看错误，比背更多代码有用

| 看见什么 | 可以怎样理解 | 先检查哪里 |
| --- | --- | --- |
| 404 | 服务没找到你要的地址 | 拼写、文件是否存在、服务器文件名单 |
| 403 | 找到了窗口，但不允许这次操作 | 是否在公网使用仅限本机的写作接口、请求来源 |
| 429 | 请求太频繁 | 稍后再试，检查接口的限流设置 |
| 503 | 服务当前未准备好 | 本项目常见为配置不全；看页面提示，不要直接认定都是密钥错误 |
| `Unexpected token` 等解析错误 | 收到的内容不符合程序预期 | JSON 逗号、引号，或 API 实际返回了 HTML 页面 |
| 页面没变化 | 文件没保存、改错页面或样式被覆盖 | 保存状态、地址、F12 生效样式 |
| 粘贴 AI 代码后出错 | 它可能假设了你项目没有的变量或结构 | 先对照实际文件与错误位置，不要连续叠加更多代码 |

## 检查命令，也用人话解释

```powershell
node --check planet.js
node --check arduino-viewer.js
```

这是检查 JavaScript 语法，像查一句话的标点和语法结构；不证明页面漂亮、逻辑正确或真实服务可用。

现有模拟接口测试可用：

```powershell
node tests/chat-api.test.mjs
node tests/guestbook.test.mjs
```

测试临时开本机端口，伪装 AI 或数据库回答，检查程序是否按预期处理。受限环境可能禁止本地端口，此时要分清是运行环境问题还是代码失败。它们不使用你的真实 AI 服务来评分，也不向真实留言库写入。

本次只写文档，没有重新运行这些测试。以后改对应功能时再执行，不必每改一个标题就重测整个系统。

## 怎样让 AI 真正帮你学习

你可以这样提问：

> 我是初学者。请只解释 resources.js 从读取 JSON 到显示卡片这一段。每次讲五行：这行输入是什么、做了什么、结果去哪。不要先替我重写全部代码。最后给我一道能在本机完成的小练习。

遇到错误时，提供“在哪个页面、做了什么、原本期待什么、实际出现什么”，以及去掉密钥后的错误信息。这样比只说“坏了”更容易定位。
