# 工业工作室与温暖沙龙 · V0.4

## 设计

嵌入式页加入女性创客、示波器、万用表、开发板与元器件抽屉的工作室场景，整体采用石墨灰、橄榄绿与暖色工作灯。英语页采用木色、琥珀灯光、茶杯与围坐交流场景，面板与气泡改为可可棕和奶油金。两页继续共享品牌、导航、布局尺度与组件体系。

配图由内置 imagegen 生成，属于氛围概念图，不用于接线或器件识别教学。文件：`assets/industrial-studio-v4.png`、`assets/warm-salon-v4.png`。提示词见 [[06-V04配图提示词]]。

## 可配置 AI 对话

用户选择先提供可配置接口，不绑定服务商。支持使用 Bearer 密钥的 OpenAI-compatible Chat Completions 文本接口；不是所有供应商原生协议都兼容。

流程：英语页 → 本地 `/api/chat` → 配置的服务商 → AI 文本回复。密钥仅在服务端读取，浏览器不保存密钥。AI 模式显式标注身份，不冒充真人母语者。

## 本地配置

1. 安装 Node.js 22 或更新版本。
2. 将项目根目录 `.env.example` 复制为 `.env`。
3. 在本机填写完整的 `CHAT_API_URL`（通常以 `/v1/chat/completions` 结尾）、`CHAT_API_KEY` 和 `CHAT_MODEL`。
4. 在项目目录运行 `node server.mjs`，打开终端中的本地网址，再进入英语页。
5. 选择“AI 对话”，发送一句话。修改 `.env` 后重启服务器。

默认只监听本机。`.env` 已被 Git 忽略，也不会通过静态路由返回。API 状态只表示配置完整，不表示密钥已经由服务商验证。

AI 上下文按房间分开，保存在当前页面内存，刷新即清空；每次请求发送有限的最近上下文。失败保留输入，不伪造回复；支持新对话。原有本地练习模式不调用 API。

GitHub Pages 只能提供静态页面，不能运行此 Node 后端。上线真实 AI 对话时需另行部署受保护的后端；当前版本面向个人本机使用。
