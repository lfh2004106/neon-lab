开始之前，先说三句。
  • 这不是考试，没有分数，做不完也没关系。
  • 每一步都有「成功信号」——看不到就停下来查对照表，不用硬猜。

WHY为什么先做这一个

你套件里东西很多，一次全学完是不现实的。这个项目只用“点阵 + UNO”，但把写程序最核心的四件事都走了一遍。

五根线，先核对

改线前先断电。核对模块丝印、电压、极性与接线，不能把“插错只是不会亮”当作保证。

使用内置 SPI 库

不用额外安装点阵驱动库。程序通过 Arduino 内置的 SPI 库向 MAX7219 发送指令。

3 秒就有反馈

上电先全亮 1 秒，作为显示链路的初步检查；还需要用图案确认方向与行列映射。

01接线

8×32 模块背面是一排 5 个针。先拔掉 USB 再插线，插完捏一下——杜邦线没插到底，是“不亮”最常见的原因。

接线前断电，确认电源与引脚。

按模块规格确认供电，避免接反、短路或供电不足；检查 VCC、GND 及三根信号线后再通电。

点阵引脚接到 UNO它是干什么的
VCC5V按模块规格供电；本项目使用 5V MAX7219 模块
GNDGND地线，必须共地
DIND11数据从这进去
CS （有的印 LOAD）D10片选：告诉它“这组数据是给你的”
CLKD13时钟：数据跟着这个节拍走

02打开 IDE，选板子和端口

使用 Arduino IDE 打开项目，选择 Arduino Uno 和实际连接的串口。不同版本的 IDE，按钮位置可能略有不同。

  1. 用 USB 线把 UNO 连到电脑

    必须是能传数据的线。很多充电线只有两根电源线，插上只会亮灯但电脑认不到。

    板子上电，并且电脑能识别它的串口；仅亮灯不能证明数据连接正常

  2. 工具 → 开发板 → Arduino Uno

    你之前用过 UNO，这里应该已经是 Uno 了。

    菜单里 Arduino Uno 前面有勾

  3. 工具 → 端口 → 选那个 COM 口

    看不清是哪个？把 USB 拔掉再看一遍菜单，少掉的那个就是它。

    菜单里出现 COM3 / COM6 之类的选项

03上传

下载 heart_matrix.ino，放在同名的 heart_matrix 文件夹中，用 Arduino IDE 打开；也可以复制下方完整代码。

  1. 先点“验证”（左上角 ✓）

    这一步检查程序能否编译，不会上传到开发板。若报错，记录完整报错信息，优先找最早出现的原因。

    底部显示编译完成；实际空间占用以你的编译结果为准

  2. 再点“上传”（→ 箭头）

    板子上的 TX/RX 灯会闪几下，大约 3~5 秒。

    底部显示“上传成功”

  3. 看板子

    如果它没动，按一下板子上的复位键（RESET）。

    点阵全亮 1 秒 → 开始“咚哒”心跳

04你会看到什么

之后 1.1 秒是一个循环。图案一直是同一个爱心，变的只是亮度——代码里的 if / else 就是在挑这四个亮度。

时间画面代码里对应的
0 — 220 ms最亮，然后快速回落t < 220　咚
220 — 340 ms亮度停在中间t < 340　停
340 — 560 ms第二下“哒”，再回落t < 560　哒
560 — 1100 ms保持微亮，爱心一直看得见else　安静

FIX出问题对照表

按“现象”找，不用从头读。

现象多半是怎么办
全亮自检都没有供电或线没插到底查 5V / GND；换一根 USB 线；杜邦线插到底再捏一下
只有一片或一半亮级联连接、供电或某片模块异常先断电核对输入端和级联连接；改为单片测试时也要对应调整程序的模块数量
爱心是倒的，像黑桃行方向反了把 #define FLIP_Y 0 改成 1，重新上传
图案错位、花掉片序、行列映射或显示方向不匹配用位置已知、转置后会变化的不对称标记逐项检查，参照下方排错笔记；不要只反复切换镜像
上传报 avrdude / 找不到端口数据线、板型、端口或驱动问题确认实际串口和数据线；兼容板需要的驱动取决于 USB 转串口芯片型号
很暗、闪烁、板子反复重启供电不足、接触不良或短路等先断电检查接线，再降低亮度排查。若用外部电源，按模块和开发板规格接线、共地，避免向 USB 回灌

点阵背面应该有 4 颗 MAX7219 芯片。如果你的没有（是 74HC595 版本），这套代码不适用，告诉我芯片型号。

05代码

源码按原文件保留。说明补充：它使用内置 SPI 库；全亮自检只能初步检查显示链路，不能证明供电余量、方向和行列映射全部正确。

BEAT_MS 1100一次心跳多少毫秒。改 600 会跳得像刚跑完步，改 1800 更平静。
BRIGHT_SCALE 100整体亮度百分比。夜里觉得刺眼就改 60。
HEART一块字符画，一个字符对一颗灯。直接改它就能换形状。

/*
 *  ------------------------------------------------------------
 *   爱心点阵 · 你的第一个 Arduino 项目
 *  ------------------------------------------------------------
 *   硬件：Arduino UNO + 8×32 MAX7219 点阵（4 片 8×8 串起来）
 *   接线：VCC -> 5V    GND -> GND    DIN -> D11
 *         CS  -> D10   CLK -> D13
 *
 *   用法：插上 USB -> 选好 Arduino Uno 和端口 -> 点“上传”。
 *        不需要安装任何库，代码会自己驱动点阵。
 *
 *   上电后先全亮 1 秒（自检：四片都亮 = 接线成功），
 *   然后爱心会一直亮着，只让亮度跟着心跳起伏。
 *  ------------------------------------------------------------
 */

#include <SPI.h>

// ===== 只有这两行可能需要你改（画面方向不对的时候）=====
#define FLIP_X 0          // 左右镜像：画面左右反了改成 1
#define FLIP_Y 0          // 上下颠倒：爱心变成“黑桃”改成 1

// ===== 两个好玩的旋钮 =====
#define BEAT_MS      1100 // 一次心跳多少毫秒：改小跳得快，改大更平静
#define BRIGHT_SCALE 100  // 整体亮度百分比：觉得刺眼就改成 60

const uint8_t PIN_CS = 10;        // CS / LOAD 接 D10
const uint8_t CHIPS  = 4;         // 4 片 8×8
const uint8_t WIDTH  = CHIPS * 8; // 一共 32 列

uint8_t canvas[WIDTH];            // 画布：一列一个字节，bit0 = 最上面那颗灯

// ------------------------------------------------------------------
//  爱心图案：'#' 是亮，'.' 是灭，一共 8 行、每行 32 个字符。
//  想换个图案？直接改这块字符画就行，一个字符对一颗灯。
// ------------------------------------------------------------------
const char *HEART[8] = {
  "............###..###............",
  "...........####..####...........",
  "..........############..........",
  "..........############..........",
  "...........##########...........",
  "............########............",
  ".............######.............",
  "...............##...............",
};

// ------------------------------------------------------------------
//  下面是可以先跳过的部分：怎么跟 MAX7219 说话
// ------------------------------------------------------------------

// 给第 chip 片（0 是最靠近 DIN 的那片）的某个寄存器写一个字节。
// 点阵是串联的，所以每次要把 4 片都“喂”一遍，其余的喂 0x00（空操作）。
void maxWrite(uint8_t chip, uint8_t reg, uint8_t value) {
  digitalWrite(PIN_CS, LOW);
  for (int8_t i = CHIPS - 1; i >= 0; i--) {
    if (i == chip) {
      SPI.transfer(reg);
      SPI.transfer(value);
    } else {
      SPI.transfer(0x00);
      SPI.transfer(0x00);
    }
  }
  digitalWrite(PIN_CS, HIGH);
}

void maxSetup() {
  for (uint8_t c = 0; c < CHIPS; c++) {
    maxWrite(c, 0x0F, 0x00);      // 关掉测试模式
    maxWrite(c, 0x0B, 0x07);      // 8 行全用
    maxWrite(c, 0x09, 0x00);      // 不译码（点阵必须这样）
    maxWrite(c, 0x0A, 0x03);      // 初始亮度
    maxWrite(c, 0x0C, 0x01);      // 开显示
  }
}

// 把画布送到点阵上。
//
// 【重要】这块 8×32 点阵是“转置”接法的：每一片的 8 个寄存器
// （0x01~0x08）对应的是 8 行，不是 8 列；每个字节的 8 个 bit 对应 8 列。
// 所以发数据前要把图像转置一下，否则爱心会被切成左右两块。
void show(uint8_t level) {
  level = (uint16_t)level * BRIGHT_SCALE / 100;   // 应用亮度旋钮
  if (level > 15) level = 15;

  for (uint8_t c = 0; c < CHIPS; c++) {
    maxWrite(c, 0x0A, level);                     // 这一片的亮度

    for (uint8_t r = 0; r < 8; r++) {             // 第 r 行
      uint8_t bits = 0;
      for (uint8_t b = 0; b < 8; b++) {           // 第 b 列
        uint8_t rr = FLIP_Y ? (7 - r) : r;        // 上下颠倒
        uint8_t bb = FLIP_X ? (7 - b) : b;        // 左右镜像
        if (canvas[c * 8 + bb] & (1 << rr)) bits |= (1 << b);
      }
      maxWrite(c, r + 1, bits);                   // 0x01~0x08 就是第 1~8 行
    }
  }
}

// 把一张 8 行的字符画刷进画布
void drawHeart(const char *art[8]) {
  memset(canvas, 0, WIDTH);
  for (uint8_t y = 0; y < 8; y++) {
    for (uint8_t x = 0; x < WIDTH; x++) {
      if (art[y][x] == '#') canvas[x] |= (1 << y);
    }
  }
}

// 上电自检：全部点亮 1 秒。四片都亮，就说明接线和供电都没问题。
void selfTest() {
  memset(canvas, 0xFF, WIDTH);
  show(6);
  delay(1000);
  memset(canvas, 0x00, WIDTH);
  show(0);
  delay(150);
}

// ------------------------------------------------------------------
//  setup / loop
// ------------------------------------------------------------------
void setup() {
  pinMode(PIN_CS, OUTPUT);
  digitalWrite(PIN_CS, HIGH);

  SPI.begin();
  SPI.setBitOrder(MSBFIRST);
  SPI.setDataMode(SPI_MODE0);
  SPI.setClockDivider(SPI_CLOCK_DIV4);   // 4 MHz，MAX7219 吃得下

  maxSetup();
  selfTest();

  drawHeart(HEART);   // 爱心画一次，之后循环里只改亮度
}

void loop() {
  uint16_t t = millis() % BEAT_MS;   // 0 ~ BEAT_MS 之间循环
  uint8_t  level;

  if (t < 220) {                     // 咚：最亮，然后快速回落
    level = 15 - (uint8_t)((uint32_t)t * 8 / 220);          // 15 -> 7
  } else if (t < 340) {              // 稍停一下
    level = 7;
  } else if (t < 560) {              // 哒：第二下，弱一点，慢一点回落
    level = 12 - (uint8_t)((uint32_t)(t - 340) * 6 / 220);  // 12 -> 6
  } else {                           // 安静：也保持能看清
    level = 5;
  }

  show(level);
  delay(15);
}
