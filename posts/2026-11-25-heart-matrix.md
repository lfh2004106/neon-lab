## 第一个项目，要让它真的亮起来

目标是用 Arduino UNO、8×32 MAX7219 点阵和五根杜邦线，显示一颗有心跳节奏的爱心。不额外安装第三方点阵库，先完成一个能观察、能解释的小作品。

## 几次猜测，为什么没有解决问题

第一种猜测是图案太暗、太小。把大小动画改成亮度动画，改善了观感，却没有解释两块奇怪亮斑。

随后检查了模块是否装反、列方向是否相反、两块板之间的接缝是否影响效果。测试提供了一些线索，但“测试看起来正常”不等于所有映射关系都正确。

转折点是重新问：**字符画里这一颗灯，到底会被写到哪个寄存器、哪个 bit？**

## 最后改的是 `show()`

画布 `canvas[32]` 按列保存。最终程序把列里的各个位取出来，重新组成当前模块需要的一行，然后写入对应寄存器。

```cpp
for (uint8_t r = 0; r < 8; r++) {
  uint8_t bits = 0;
  for (uint8_t b = 0; b < 8; b++) {
    if (canvas[c * 8 + b] & (1 << r)) bits |= (1 << b);
  }
  maxWrite(c, r + 1, bits);
}
```

网页展示的最终 `.ino` 保留原始文件。完整版本还有方向开关、SPI 初始化、全亮自检和亮度控制。

## 留下的经验

- 先让简单效果工作，再慢慢加设计。
- 一次只改一件事，记下预期和实际结果。
- 调试图案要能区分你正在检查的变换。
- 对比灯的位置，比凭整体观感猜原因更有效。
- 对照片做分析时，留意透视和曝光带来的误差。

## 重读原笔记时补上的说明

全亮自检只说明显示链路在当时条件下能工作，不能证明供电余量与映射都正确。转置是行列互换，不等于旋转；某个 L 图案是否能检查转置，要看它的具体几何形状。

原文“对角线可以确认转置”的建议也需要修正：主对角线转置后不变。下次可以从位置已知、转置后会变化的单点或组合标记开始，逐片建立坐标对应关系。
