WRITE IT DOWN

今天的实验，
值得被记住。

一篇合格的个人博客不需要写得漂亮，只要能让未来的你复原现场：目标是什么、改了什么、看到了什么、下一步怎么走。

  1. 01在本机运行 node server.mjs，填写表单可直接发布；
  2. 02线上静态部署无法写文件，改用「下载 Markdown」；
  3. 03把文件放进 posts/，运行 npm run posts 或直接提交；
  4. 04推送到 GitHub，Render 会自动重新部署。

日志会公开显示在这个页面；不要把密钥、个人隐私或他人信息写进正文。
